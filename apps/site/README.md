# Tensum Site

This SvelteKit app is the product site and interactive playground for the `tensum` GSAP plugin.

Run it from the repository root:

```bash
pnpm dev
```

The app uses Svelte 5, Tailwind CSS, GSAP, and shadcn-svelte preset `bK05dzlM8`. Physics and GSAP integration stay in the single workspace package; playground components contain controls, rendering, and telemetry only.
